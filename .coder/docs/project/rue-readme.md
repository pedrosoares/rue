# README.md

The project root `README.md` was created to serve as the GitHub repository landing page. It covers:

- Project overview and features
- Quick start guide (prerequisites, build, first app)
- Core concepts (reactivity, component model, virtual DOM)
- `html!` macro syntax reference
- API summary table
- Project structure with file tree
- Data flow diagram (text-based)
- Build & run instructions
- Dependencies
- Vue 3 comparison table
- License information

The README is written in markdown with HTML for styled badges and centering. It's designed to be informative for both newcomers evaluating the framework and developers familiar with Vue 3 looking for Rust/WASM alternatives.
